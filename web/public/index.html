Customer Terraform Deployment Blueprint (Cloud Run + IAP)

                
Ready-to-apply infrastructure code in terraform/ provisioning dedicated Service Accounts, IAP access bindings, and the isolated Gen2 gVisor Sandbox Worker.

              

              Least-Privilege IAM
            

            
# 1. Configure customer Project ID and IAP allowed employee groups
cat <<EOF > terraform/terraform.tfvars
project_id              = "customer-genai-prod"
region                  = "us-central1"
iap_allowed_members     = [
  "group:ai-skill-builders@customer.com",
  "user:lead-ce@customer.com"
]
web_container_image     = "us-central1-docker.pkg.dev/customer-genai-prod/skill-builder/skill-builder-web:latest"
sandbox_container_image = "us-central1-docker.pkg.dev/customer-genai-prod/skill-builder/skill-builder-sandbox:latest"
discovery_engine_app_id = "gemini-enterprise-spark-prod"
EOF

# 2. Provision Dedicated Service Accounts, IAP, VPC Lock, & Cloud Run Gen2 Services
terraform -chdir=terraform init
terraform -chdir=terraform apply

# Provisioned Resources:
# - google_service_account.web_sa (skill-builder-web-sa)
# - google_service_account.sandbox_sa (skill-builder-sandbox-sa with AGY_ADC_AUTH=true)
# - google_cloud_run_v2_service.web_app (iap_enabled = true)
# - google_iap_web_cloud_run_service_iam_member.iap_allowed_users (roles/iap.httpsResourceAccessor)
# - google_cloud_run_v2_service.sandbox_worker (EXECUTION_ENVIRONMENT_GEN2 + Direct VPC Egress lock)
